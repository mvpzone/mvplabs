# Skills

Reusable [agent skills](https://agentskills.io/specification) for Claude Code and compatible agent CLIs. Each folder is a self-contained skill: copy it into a `skills/` directory your agent reads.

| Skill | What it does |
|-------|--------------|
| [llm-council](llm-council/) | Put a hard question to several independent sub-agents, have them rank each other's answers anonymously, then synthesise one verdict that keeps the disagreements visible |
