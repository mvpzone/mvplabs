# Katas

Small, single-lesson exercises: one bug, one fix, one test, 10–20 minutes. Each folder has the broken and the fixed
code side by side, and a walkthrough on [devnull.fyi/labs](https://devnull.fyi/labs/).

| Kata | Lesson | Walkthrough |
|---|---|---|
| [strict-mocks](strict-mocks/) | A mock that answers anything proves only that your code asked | [15 min](https://devnull.fyi/labs/your-mock-answers-methods-the-sdk-doesnt-have/) |
